# Student Money Manager 💰

A simple, mobile-friendly student expense tracker made with HTML, CSS and JavaScript.

## Features
- Add received money and expenses
- Automatic balance calculation
- Categories
- Date and notes
- Search transaction history
- Delete individual transactions
- Clear all data
- Data stored in browser `localStorage`
- Works on mobile and desktop
- No backend required

## Run
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Select the `main` branch and `/root` folder.
5. Save and open the generated Pages URL.

## Important
This version stores data only in the browser/device. If you want login, cloud sync, multiple students, export to Excel/PDF, or Firebase/Supabase, those can be added later.
